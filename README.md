# SoundWatch

Đồng hồ nhận diện âm thanh môi trường cho người khiếm thính — đề tài môn AI cho hệ thống nhúng.

Giai đoạn hiện tại: Proof-of-Concept chạy hoàn toàn trên máy tính, chuẩn bị port sang vi điều khiển (ESP32-S3 / nRF52840) với TFLite Micro.

Kế hoạch triển khai chi tiết: [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md)
